# ALRT production release blockers checklist

Date: 21 October 2026
Status: working list

## Release-blocker areas

1. Navigation / route checking works end to end on the production backend
2. Saved-location alerts show real saved-location alerts, not only current map-view alerts
3. Login persists reliably across relaunch
4. Safety Profile / For You appears where the hazard supports it
5. Learning/safety guide modules appear consistently for supported hazard categories
6. Alert detail wording is easy to understand for official traffic / planned / event alerts
7. Tell your people card is compact and visually secondary to the alert content
8. Tell your people group selection uses a picker/select control, not all-group chips
9. Search can start a journey / route / navigation flow directly
10. Public transport route options are visible and clearly labelled
11. RevenueCat / prod billing is connected correctly
12. Push / auth / admin / Ask ALRT / sources are production-wired and verified
