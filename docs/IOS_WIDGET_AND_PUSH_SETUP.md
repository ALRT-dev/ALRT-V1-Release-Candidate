# iOS Widget & Time-Sensitive Push — Setup Steps for Matt

These two items are blocked on Apple Developer portal + Xcode access.
They **cannot** be done from code or CI alone. Both need to be done together
since they share the App Group entitlement.

---

## 1. iOS Home Screen Widget (WidgetKit)

**What it is:** The ALRT family/alert home screen widget for iOS.  
**Status:** Swift sources exist at `frontend/ios/AlrtWidget/` but the
WidgetKit target has NOT been added to `Runner.xcodeproj` — so it compiles
out of the build and never appears on iOS.

### Steps (do in Xcode with Apple Developer account open)

1. **Open the project in Xcode**
   ```
   open frontend/ios/Runner.xcworkspace
   ```

2. **Add WidgetKit target**
   - File → New → Target → Widget Extension
   - Product Name: `AlrtWidget`
   - Bundle ID: `com.safetyalrt.alrt.dev.AlrtWidget` (dev) / `com.safetyalrt.alrt.AlrtWidget` (prod)
   - Uncheck "Include Configuration Intent" (ALRT uses static widget, no user intent)
   - Click Finish

3. **Replace the generated Swift files** with the existing ones at:
   `frontend/ios/AlrtWidget/AlrtAlertsWidget.swift`
   `frontend/ios/AlrtWidget/AlrtFamilyWidget.swift`
   `frontend/ios/AlrtWidget/AlrtWidgetBundle.swift`

4. **Add the App Group capability** to BOTH the Runner target AND the AlrtWidget target:
   - Signing & Capabilities → + Capability → App Groups
   - Group name: `group.com.safetyalrt.alrt.dev` (dev) / `group.com.safetyalrt.alrt` (prod)
   - This is how the Flutter app and the widget share data

5. **Add App Group to the entitlements files**
   The entitlement files already exist:
   - `frontend/ios/AlrtWidget/AlrtWidget.entitlements`
   - `frontend/ios/AlrtWidget/AlrtWidget-dev.entitlements`
   Confirm each contains the correct App Group ID.

6. **Register the App Group in Apple Developer portal**
   - developer.apple.com → Identifiers → App Groups → +
   - Add `group.com.safetyalrt.alrt.dev` (and prod equivalent)
   - Add the group to both the ALRT Dev App ID and the AlrtWidget App ID

7. **Regenerate provisioning profiles** via fastlane match:
   ```bash
   cd frontend/ios
   bundle exec fastlane match appstore --app_identifier \
     "com.safetyalrt.alrt.dev,com.safetyalrt.alrt.dev.AlrtWidget"
   ```

8. **Set the Widget target's build settings**
   - Use the `Widget.xcconfig` at `frontend/ios/AlrtWidget/Widget.xcconfig`
   - Embed the widget extension in the Runner target:
     Runner → Build Phases → Embed App Extensions → + AlrtWidget.appex

9. **Test:** Add a widget to your iOS home screen; it should show family status
   and the top alert. Tapping it should deep-link into the app.

## 2. Time-Sensitive Push Notifications (iOS)

**What it is:** Allows ALRT push notifications to break through iPhone Focus
modes (Do Not Disturb, Sleep) for Emergency Warning and Watch & Act alerts.  
Without this, urgent alerts are silenced when Focus is on — they still arrive
but make no sound.

**Status:** Not enabled on the `com.safetyalrt.alrt.dev` App ID.

### Steps

1. **Enable Time Sensitive Notifications in Apple Developer portal**
   - developer.apple.com → Identifiers → `com.safetyalrt.alrt.dev`
   - Additional Capabilities → Time Sensitive Notifications → Enable
   - Regenerate the provisioning profile afterwards

2. **Add entitlement to the app in Xcode**
   - Runner target → Signing & Capabilities → + Capability → Time Sensitive Notifications
   - This adds `com.apple.developer.usernotifications.time-sensitive` to the entitlement

3. **Update the backend push payload** (`backend/src/services/notification.service.ts`)
   When sending Emergency Warning or Watch & Act alerts, add:
   ```json
   {
     "apns": {
       "payload": {
         "aps": {
           "interruption-level": "time-sensitive"
         }
       }
     }
   }
   ```
   The backend already structures FCM messages with `apns` blocks — add
   `interruption-level: "time-sensitive"` for `HazardSeverityBand.action`
   and `HazardSeverityBand.critical` (Watch & Act / Emergency Warning only).

4. **Regenerate match profiles** after portal change:
   ```bash
   bundle exec fastlane match appstore \
     --app_identifier "com.safetyalrt.alrt.dev"
   ```

5. **Test:** Enable Focus / Do Not Disturb on an iPhone. Trigger a Watch & Act
   or Emergency Warning alert. It should appear with sound despite Focus being on.
